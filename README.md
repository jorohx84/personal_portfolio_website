# Johannes Roth — Portfolio

Angular 22 portfolio website inspired by the visual language of the Davis HTML portfolio template, rebuilt from scratch for Johannes Roth.

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:4200

## Build

```bash
npm run build
```

## Customize

Main content and project data are in `src/app/app.component.ts` and `src/app/app.component.html`.
Global styling is in `src/styles.scss`.
